## 🌟 Key Features

- ⚡ **Interactive Python Test Runner Simulator**: An authentic terminal console running simulated `pytest` automated test suites with animated execution and pass counters.
- 🌓 **Dual Theme Engine**: Seamless Dark and Light modes with system preference detection and `localStorage` persistence.
- 🎯 **Interactive Technical Skills Matrix**: Category filter tabs (`All`, `QA & Testing`, `Python & Data`, `Development & DB`, `Languages`) with responsive cards.
- ⏳ **Career Milestones & Timeline**: Detailed employment history at **IMS Group** *(Quality Analyst)*, **Qspider** *(Full Stack Developer)*, and **One20Mins** *(Customer Relations Executive)*.
- 📂 **Applied Projects & QA Case Studies**: Showcases automation suites, SQL/CSV data reconciliation pipelines, defect trackers, and AI/ML exploratory analysis models.
- 🖨️ **Print / Recruiter Resume Mode**: Integrated 1-click **Resume** button triggering an optimized, clean `@media print` layout ready for PDF export or printing.
- 📋 **1-Click Clipboard Utilities**: Instant copy buttons for Email and Phone with animated feedback toast notifications.
- ✉️ **Interactive Contact System**: Client-side validated contact form with dynamic prefilled `mailto:` generator.
- 📱 **100% Mobile Responsive**: Fluid layouts, responsive typography, and mobile slide-down navigation menu.
- 🚀 **Zero Dependencies**: Pure HTML5, modern Vanilla CSS, and native JavaScript — no build steps or heavy frameworks required.

## 🚀 Getting Started & Local Preview

You can run and preview this portfolio website locally using any of the following methods:

### Option 1: Direct Browser Launch (Simplest)
Double-click [`index.html`](index.html) or right-click and choose **Open with > Chrome / Edge / Firefox / Safari**. No local server is required.

---

### Option 2: Using the Included Node.js Server
If you have **Node.js** installed:

```bash
# Start the local server
node server.js
```
Then open your browser and navigate to:
```
http://localhost:3000
```

---

### Option 3: Using Python HTTP Server
If you prefer Python:

```bash
# Python 3
python -m http.server 3000
```
Then navigate to `http://localhost:3000`.

## 🚢 Free Deployment Guide

This portfolio can be deployed for free within minutes:

### Deploy to GitHub Pages (Recommended)
1. Initialize Git in the project root:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Smit Parikh Portfolio"
   ```
2. Create a new repository on your GitHub account (e.g., `smit-parikh-portfolio` or `SmitParikh1608.github.io`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/SmitParikh1608/smit-parikh-portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, go to **Settings > Pages > Branch: `main` > Save**. Your site will be live at `https://SmitParikh1608.github.io/smit-parikh-portfolio/`.

### Deploy to Vercel or Netlify
- **Vercel**: Drag and drop the folder into the [Vercel Dashboard](https://vercel.com/) or run `npx vercel`.
- **Netlify**: Drag and drop the project folder directly into [Netlify Drop](https://app.netlify.com/drop).
